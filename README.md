# 📱 React Native – TP1, TP2 e TP3

Este repositório reúne os **três Testes de Performance (TPs)** da disciplina **Desenvolvimento Mobile com React Native**, do curso de **Engenharia de Software - Instituto Infnet**.  
O objetivo é demonstrar o aprendizado progressivo no uso do **React Native** e **Expo**, por meio da implementação de diversos exercícios práticos.

---

## 🎯 Objetivo Geral

Desenvolver aplicativos mobile simples e intermediários utilizando o **framework React Native**, praticando desde os componentes básicos até a criação de aplicações com **navegação**, **consumo de APIs** e **manipulação de listas**.

## 🧠 Conteúdo dos TPs

### 📘 TP1 – Fundamentos do React Native
Foco: primeiros passos, componentes básicos e manipulação de estado.

- Exibir mensagens dinâmicas com interpolação.
- Utilização de componentes: `Text`, `Button`, `Image`, `TouchableOpacity`, `TouchableHighlight`, `Pressable`.
- Criação de aplicativos simples (Contador, Par/Ímpar, Palíndromo, Calculadora, Quiz).
- Introdução à componentização.
- Texto dissertativo sobre **arquitetura React Native**.

---

### 📗 TP2 – Layout e Navegação
Foco: Flexbox e navegação entre telas.

- Layouts verticais, horizontais e em grade.
- Alinhamento e espaçamento de elementos.
- Criação de **listas e carrosséis**.
- Implementação de navegação (`Drawer` e `Bottom Navigation`).
- Aplicações práticas: **Currículo App**, **Carrinho de Compras**, **Rede Social de Viagens**, **Quiz** e **Match App**.

---

### 📙 TP3 – Consumo de APIs e Listas Dinâmicas
Foco: manipulação de dados externos e renderização dinâmica.

- Uso de `ScrollView`, `FlatList` e `SectionList`.
- Filtros, ordenação e carregamento tardio.
- Consumo de APIs externas (Firebase, Câmara, IBGE, OpenLibrary).
- Implementação de indicadores de carregamento e Pull-to-Refresh.
- Aplicações completas: **Inventário de Livros**, **Democracia Ativa**, **Notícias IBGE**.
